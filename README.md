# Auth Lab

Backend API with user registration, JWT authentication, and protected routes.

## Tech Stack

- NestJS + TypeScript
- Prisma + PostgreSQL
- Docker
- JWT + Argon2
- Swagger

## Features

- [ ] User registration
- [ ] Login with email and password
- [ ] Password hashing with Argon2
- [ ] Access and Refresh tokens
- [ ] Token refresh
- [ ] Refresh Token stored in an HttpOnly Cookie
- [ ] User logout
- [ ] Protected routes using Guards
- [ ] User profile
- [ ] Role-based access control (RBAC)

## Getting Started

```bash
pnpm install
pnpm start:dev
```
